# 📖 Книга рецептов

Консольное приложение на Python для поиска рецептов. Позволяет узнать, что можно приготовить из имеющихся продуктов, или найти рецепт по названию.

## Возможности

- **Поиск по продуктам** — введите продукты, которые есть у вас дома, и программа покажет:
  - рецепты, которые можно приготовить прямо сейчас
  - рецепты, для которых не хватает лишь нескольких ингредиентов
- **Поиск по названию** — найдите рецепт по полному или частичному названию

## Структура проекта

```
.
├── recipes_result.py   # основной скрипт
└── recipes.txt         # база рецептов
```

## Установка и запуск

1. Убедитесь, что установлен Python 3.x:
   ```bash
   python --version
   ```

2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/recipes-book.git
   cd recipes-book
   ```

3. Запустите скрипт:
   ```bash
   python recipes_result.py
   ```

> Файлы `recipes_result.py` и `recipes.txt` должны находиться в одной папке.

## Использование

При запуске программа выводит список всех доступных рецептов и предлагает выбрать режим поиска:

```
=== КНИГА РЕЦЕПТОВ ===
Количество рецептов в книге: 30
Список рецептов:
- Борщ
- Оливье
...

Выберите режим:
1 - Поиск по продуктам
2 - Поиск по названию
```

### Режим 1 — Поиск по продуктам

Введите продукты через запятую:
```
Введите продукты (через запятую): яйца, молоко, мука, сахар

✅ Можно приготовить:

• Блины
  Ингредиенты: мука, яйца, молоко, сахар, соль, масло сливочное, масло растительное

🛒 Нужно докупить:

• Оладьи
  Не хватает: кефир, сода, масло растительное
```

### Режим 2 — Поиск по названию

Можно вводить как полное название, так и его часть:
```
Введите название рецепта: паста

• Паста карбонара
  Ингредиенты: спагетти, бекон, яйца, пармезан, чеснок, чёрный перец

• Паста болоньезе
  Ингредиенты: спагетти, фарш говяжий, лук, морковь, сельдерей, томаты, красное вино
```

## Формат файла recipes.txt

Каждый рецепт — одна строка:
```
Название рецепта: ингредиент1, ингредиент2, ингредиент3
```

Пример:
```
Борщ: свёкла, капуста, картофель, морковь, лук, томатная паста, говядина, сметана, чеснок
Омлет с овощами: яйца, молоко, болгарский перец, помидоры, лук, масло сливочное
```

Чтобы добавить новый рецепт, просто допишите строку в файл `recipes.txt` в том же формате.
